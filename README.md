# 🚌 Подсчёт автобусов на остановке с помощью YOLOv8

Веб-приложение на **Flask** для обнаружения и подсчёта количества автобусов на остановке по фотографии. Для детекции используется нейросетевая модель **YOLOv8** (по умолчанию — `yolov8x-world`).

> 🎓 Учебный проект, выполненный в рамках обучения в вузе.

---

## 📋 Возможности

- Загрузка изображения через веб-интерфейс
- Автоматическое обнаружение автобусов на фото с помощью модели YOLOv8
- Подсчёт количества найденных автобусов
- Ведение журнала обработанных изображений
- Выгрузка отчёта по всем обработанным изображениям

## 🛠 Технологии

- Python
- Flask
- Ultralytics YOLOv8
- OpenCV

---

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/nullkat/busdetector.git
cd busdetector
```

### 2. Создайте и активируйте виртуальное окружение

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. Установите зависимости

```bash
pip install -r requirements.txt
```

### 4. Настройки приложения

Приложение поддерживает настройку через файл `.env`. Это необязательно — без него будут использованы значения по умолчанию. Чтобы изменить настройки, скопируйте `env.example` в `.env` и отредактируйте нужные значения:

**Windows:**

```bash
copy env.example .env
```

**Linux / macOS:**

```bash
cp env.example .env
```

Содержимое `env.example`:

```env
HOST=127.0.0.1
# PORT=5000
MODEL=yolov8x-world
```

| Переменная | Описание                        | Значение по умолчанию |
|------------|---------------------------------|-----------------------|
| `HOST`     | Адрес, на котором запускается сервер | `127.0.0.1`      |
| `PORT`     | Порт сервера                    | `5000`                |
| `MODEL`    | Используемая модель YOLOv8      | `yolov8x-world`       |

### 5. Запустите приложение

```bash
python main.py
```

После запуска приложение будет доступно по адресу: **http://127.0.0.1:5000**

> ℹ️ При первом запуске начнётся автоматическое скачивание модели — это займёт некоторое время.

---

## 📖 Использование

1. Откройте в браузере http://127.0.0.1:5000
2. Нажмите кнопку выбора файла и загрузите изображение остановки
3. Нажмите кнопку **«Подсчитать автобусы»**
4. Получите результат — количество обнаруженных автобусов на изображении
5. Чтобы выгрузить отчёт по всем обработанным изображениям, нажмите кнопку **«Скачать журнал»**
